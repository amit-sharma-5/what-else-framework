### Debt — newly introduced

**N5. Skill version header not bumped after v1.3.0 release**

The skill header reads `**Skill version:** v1.2.0` but the repo was tagged `v1.3.0` when Engineer Notes were added. Anyone checking their installed version against the tag will see a mismatch.

*Fix:* Update header to `v1.3.0`.

---

**N6. Pinned template URL (v1.0.0) is stale — template has changed since that tag**

The skill fetches the EDR template from `v1.0.0`:
```
https://raw.githubusercontent.com/.../v1.0.0/templates/engineering-decision-record.md
```

But the template at `v1.0.0` is missing `## Outcome` and `## Engineer Notes` — both added in `v1.2.0` and `v1.3.0`. Any EDR generated now will be missing these sections unless the pinned template URL is updated.

Unlike dimensions (intentionally stable), the template should track the skill version — it is part of the output contract, not the review heuristics.

*Fix:* Pin template to `v1.3.0`. Keep dimensions at `v1.0.0` (unchanged, still correct). Document this distinction: dimensions and template are pinned separately for different reasons.

## Decisions Made This Run

| Template and dimensions pinned independently | Template is output contract — should match skill version. Dimensions are review heuristics — stable, only upgraded deliberately. |
